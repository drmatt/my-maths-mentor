# Photos

Drop real photos here and the site uses them automatically (optimised to AVIF/WebP at build time):

| File name (any of .jpg .jpeg .png .webp .avif) | Where it appears |
| --- | --- |
| `viaduct` | Hero (Stockport Viaduct) |
| `town-hall` | "Maths is all around Stockport" |
| `market-hall` | "Maths is all around Stockport" |
| `mersey` | "Maths is all around Stockport" |
| `emma` | Meet Emma (portrait, ideally 4:5) |

Before adding a photo:

- Make sure you have the rights to use it (your own photo, or a licence that allows website use).
- No photos of children, and nothing that identifies Emma's home, unless everyone involved has given permission.

The handwritten maths notes are drawn on top of each landmark photo. After adding a photo, check the
notes still line up and move them in `src/components/sketches/<Landmark>.astro` (the `notes` group) if not.
For the viaduct, check the real arch shape before claiming the circle equation fits it.
